# mappin

# スマートフォンで使う
このアプリはPWAに対応しています。https://komorisoto.github.io/mappin/ をスマートフォンで開き、ブラウザーのメニューから「ホーム画面に追加」を選ぶと、アプリのように全画面で起動できます。

- iPhone / iPad: Safariの共有メニューから「ホーム画面に追加」
- Android: Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」
